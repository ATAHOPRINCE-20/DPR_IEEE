# Results Directory
This directory stores baseline experiment outputs:
- `aggregate_metrics.csv`: Summary of Recall@1, Recall@5, MRR@10, and Mean query latency (ms).
- `minimum_evaluation_report.csv`: Exact benchmark comparison table format requested by IEEE CIS.
- `per_question_results.csv`: Per-query breakdown of retrieved passage IDs, reciprocal ranks, and latencies.
- `error_analysis.md`: 5-case qualitative error analysis contrasting lexical vs. dense retrieval.
